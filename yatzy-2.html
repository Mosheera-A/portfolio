Yatzy – Technical Overview

This project is a browser-based implementation of the classic Yatzy dice game. It uses semantic HTML, modular JavaScript, and lightweight CSS to provide a clean UI and a clear separation between presentation and game logic. The code is structured with distinct responsibilities: a Dice module for rolling and holding dice, a YatzyEngine module for scoring and category validation, and a YatzyGame controller that coordinates players, rounds, and UI updates. The design enables easy extension—for example, adding a client-server mode (via Node/Express) for multiplayer or persistence in later labs.

Highlights

Architecture

  • Modular JS: Dice, YatzyEngine, and YatzyGame are split into focused modules with clean interfaces.
  • UI vs Logic: DOM/UI updates are kept separate from scoring/validation logic to simplify testing and future refactors.
  • Extensibility: Designed to add Express/REST endpoints later for saving scores and enabling remote play.

Game Mechanics

  • Dice workflow: Roll up to three times per round, selectively holding dice between rolls.
  • Scoring: Categories include Ones–Sixes, Three/Four of a Kind, Full House, Small/Large Straight, Chance, and Yatzy, with an Upper Section bonus rule.
  • State management: Tracks players, current turn, round number, and per-category selections in a score table.

Key Files

  • index.html – Main portfolio and entry point to this project.
  • portf.css – Shared site styling so this page visually matches the portfolio.
  • yatz.js – Yatzy modules (Dice, YatzyEngine, YatzyGame) and UI hookup code.

Sample API (Pseudo-usage)

// Import modules
import {{ Dice }} from './dice.js';
import {{ YatzyEngine }} from './yatzyEngine.js';
import {{ YatzyGame }} from './yatz.js';

const game = new YatzyGame(['Player 1']);
game.startNewGame();

// Roll and hold dice
game.dice.roll();
game.dice.hold([0, 2]); // example: hold die #1 and #3

// Score a category
const score = game.engine.calculateScore('Full House', game.dice.values);
game.engine.commitScore('Full House', score);

Note: File/module names can vary depending on how you organized the lab files.
